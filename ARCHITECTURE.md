## Vector Encoding & Distance Calculation

```
        SKILL VECTOR ENCODING
        ======================

    Participant Skills: {React:5, JavaScript:4}
         ?
    Skill Index: {React: 0, JavaScript: 1, ..., Total: N}
         ?
    Create vector of size N, initialized to 0.0
         ?
    For each skill:
      vector[index] = proficiency / 5.0
         ?
    Result: [1.0, 0.8, 0.0, ..., 0.0]
         ?
    This vector represents the participant's skill profile
    normalized to [0, 1] range


        EUCLIDEAN DISTANCE
        ==================

    Vector A: [1.0, 0.8, 0.5]
    Vector B: [0.9, 0.7, 0.6]
         ?
    distance = ?[(1.0-0.9)² + (0.8-0.7)² + (0.5-0.6)²]
    distance = ?[0.01 + 0.01 + 0.01]
    distance = ?0.03 ? 0.173
         ?
    Used by K-means to find nearest cluster


        COSINE SIMILARITY
        =================

    Vector A: [1.0, 0.8]
    Vector B: [1.0, 0.8]
         ?
    dotProduct = (1.0×1.0) + (0.8×0.8) = 1.64
    magA = ?(1.0² + 0.8²) = 1.281
    magB = ?(1.0² + 0.8²) = 1.281
         ?
    similarity = 1.64 / (1.281 × 1.281) = 1.0
         ?
    Range: [-1, 1], where 1 = identical
```

## Team Balancing Algorithm

```
        SKILL DIVERSITY BALANCING
        ==========================

    INPUT: Participants[], Team Size
         ?
    [Sort by Diversity]
    For each participant:
      ?? Count unique skill categories
      ?? Sum proficiency levels
      ?? Score = categories × avg_proficiency
         ?
    Sort descending by score
         ?
    [Greedy Selection]
    For each team to form:
      ?? Initialize empty team
      ?? For each participant (sorted):
      ?   ?? Add to team
      ?   ?? Count teams [teamSize] reached?
      ?   ?? Check balance requirements
      ?? If balanced: keep team
      ?? Else: try next participant
         ?
    OUTPUT: List<List<Participant>> (balanced teams)
```

## Workflow Sequence

```
        COMPLETE WORKFLOW
        =================

    1. Registration Phase
       Participant ? RegisterParticipant ? Stored
                  ? AddSkills ? Skills associated
                  ? AddInterests ? Interests recorded
       ? Status: Submitted

    2. Organization Phase
       Organizer ? ConfigureEvent (size, constraints)
       ? Status: Ready

    3. Clustering Phase
       System ? ClusterParticipants() ? Algorithm runs
              ? Convergence reached
              ? Clusters returned
       ? Status: Suggested teams

    4. Team Formation Phase
       System ? CreateTeams() ? Teams created
              ? AddMembers() ? Participants assigned
       ? Status: Draft

    5. Review Phase
       Organizer ? ViewTeamComposition ? See assignments
                 ? CheckBalance ? Verify diversity
       ? Status: Reviewed

    6. Adjustment Phase (Optional)
       Organizer ? MoveParticipant() ? Adjust manually
                 ? Audit logged ? Change recorded
       ? Status: Adjusted

    7. Finalization Phase
       Organizer ? LockTeams() ? Teams finalized
       ? Status: Locked

    8. Export Phase
       System ? ExportData() ? CSV generated
              ? FileWrite() ? File saved
       ? Status: Exported

    9. Event Phase
       Event ? HackathonRuns ? Teams work together
       ? Status: Active

    10. Completion Phase
        Teams ? Submit Results ? Event ends
        ? Status: Completed
```
