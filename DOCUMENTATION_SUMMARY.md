## ?? Key Takeaways

### **What is TeamWeave?**
An intelligent hackathon team matcher that uses AI/ML clustering to automatically form balanced, full-stack teams.

### **Why is it useful?**
- Eliminates manual, time-consuming team formation
- Ensures every team has full-stack coverage
- Provides audit trail of all changes
- Allows manual adjustments when needed
- Exports data for analysis

### **How does it work?**
1. **Phase 1**: K-Means clustering (skill vector diversity)
2. **Phase 2**: Greedy assignment (maximize pillar coverage)
3. **Phase 3**: Swap optimization (improve combined coverage)

### **What are the key technologies?**
- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript
- **Backend**: Node.js, Express.js, Mongoose
- **Database**: MongoDB (embedded or remote)
- **Optional Service**: Python FastAPI microservice

### **How to get started?**
```bash
npm install && pip install -r requirements.txt
python app.py & npm start
# Open http://localhost:3000
```
